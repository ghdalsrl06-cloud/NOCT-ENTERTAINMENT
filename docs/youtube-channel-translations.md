# NOCT ENTERTAINMENT 유튜브 채널 번역

유튜브 스튜디오 → 맞춤설정 → 기본 정보 → **채널 번역** 에 붙여넣는 용도.
원본 언어는 **한국어**, 채널 이름은 브랜드라서 모든 언어에서 **NOCT ENTERTAINMENT** 그대로 둡니다.
번역 언어 드롭다운에서 고를 항목 이름을 각 섹션 제목에 그대로 적어 두었습니다.

```

밤에 어울린다면 무엇이든 NOCT의 음악입니다.
```

## 붙여넣는 순서

1. 채널 번역 창에서 **번역 언어** 드롭다운 → 위 섹션 제목과 같은 항목 선택
2. 채널 이름 칸에 `NOCT ENTERTAINMENT`
3. 채널 설명 칸에 해당 언어 코드블록 내용 붙여넣기
4. 완료 → 다음 언어 반복

한국어 원본 설명을 바꾸면 번역도 같이 바꿔야 합니다. 이 파일을 먼저 고친 뒤 유튜브에 다시 붙여넣으세요.
